# 事先登記的假說總表

本專題後期的檢驗，都先把「要驗什麼、用什麼資料、怎樣算通過」寫在程式開頭的說明裡，再執行。
這份文件把散落在各程式的假說集中起來。**通過與未通過一律照實列出。**

原則：

- **開發與驗證分開**：規則或關鍵字在一段資料上找（探索），驗證時一字不改套到沒用過的資料。驗證資料有兩種：
  - **沒看過的股票**：原本 265 檔之外的 889 檔（全市場 1,154 檔扣掉 265 檔）。
  - **沒看過的年份**：2001–2013（TEJ 舊年份股價）、2025。
- **多重檢定**：同一批同時檢定 k 個假說時，門檻用 Bonferroni（p < 0.05 / k）。
- **t 值**：日頻檢定依交易日群聚；事件研究依事件月份群聚（先算每月平均，再對月平均做 t）；逐年滾動的模型增量對 7 個測試年做 t（自由度 6）。
- 標記：✅ 通過｜❌ 未通過｜⚠️ 方向一致但未達門檻。
