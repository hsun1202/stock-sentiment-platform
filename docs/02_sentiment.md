# 研究二：散戶「說」的——PTT 與 CMoney 情緒能不能預測

## 問題

PTT 股板留言與 CMoney 同學會貼文的情緒，能不能預測個股隔天的漲跌與報酬？換掉分類器、平台、股價來源、預測目標之後，結論會不會改變？

## 資料與情緒量法

- **PTT**：2015–2025 股板 2,021 萬則留言；以文章標題配對到 265 檔，得個股留言 231 萬則。每則留言有時間戳。
- **情緒分類**：Breeze（台灣大型語言模型）三分類（正／負／中立）；每日淨情緒 = (正 − 負) / (正 + 負)。
- **時間對齊**：只用「隔天開盤前」已發布的留言（t 日收盤前＋收盤後到 t+1 開盤前）。
- **CMoney**：2020–2024 重爬 122 萬篇貼文（每個交易日收盤前抽樣），清理後 107 萬篇；用 CMoney 自己的作者自標與重新訓練的模型分類。

## 結果

### 1. 預測隔天漲跌（XGBoost、逐年滾動、測試年 2018–2024）

| 情緒因子 | 準確度增量 ΔAUC | 顯著年數 |
|---|---|---|
| F1 淨情緒 | −0.0001 | 0 / 7 |
| F2 推噓比 | −0.0002 | 0 / 7 |
| F3 情緒變化 | −0.0004 | 0 / 7 |
| F4 意見分歧度 | −0.0002 | 0 / 7 |
| F5 [標的] 文多空（2,549 篇） | −0.0001 | 0 / 7 |
| F6 可信度加權 | −0.0002 | 0 / 7 |
| LSTM 版（＋PTT） | +0.0002 | 1 / 7 |
| 邏輯迴歸版 | +0.0000 | — |

程式：`retail_test_v4.py`、`sentiment_factor_zoo.py`、`lstm_direction_v4.py`、`logreg_direction_v4.py`

### 2. 為什麼預測不了

- **59.5%** 的留言在收盤 13:30 之後才發；舊版「同日訊號」是時間錯置，放對時間就歸零。
- 格蘭傑檢驗：股價 → 情緒 F ≈ 470，情緒 → 股價只有約六分之一（`granger_ptt.py`）。
- 事件研究：情緒強正的股票，留言前 20 天已漲 **+5.6%**、當天 +0.95%，之後 1/5/20 天只有 +0.13/+0.21/+0.08%（`ptt_event_study.py`）。

### 3. 只用 PTT 情緒交易（`ptt_rule_test.py`、`ptt_cc_deepdive.py`）

- 規則「情緒 > 0 就買、< 0 就賣」：猜對約 47%，未扣成本每筆 +4~6 bp，扣成本（32~59 bp）十年虧光。
- 只用 PTT 特徵的模型：方向 AUC 0.50（亂猜）。
- 唯一殘留：控制今天漲跌等變數後，對隔夜報酬 +4.3 bp（t=3.6）；但 **2025 樣本外反轉為 −9.9 bp（t=−2.6）**（`stock_ptt_2025_test.py`）。

### 4. 換掉可能有問題的環節

| 換掉什麼 | 作法 | 結果 |
|---|---|---|
| 情緒分類器 | 以 Claude 逐則重標 5,194 則留言當標準答案；微調中文 BERT（與標準答案一致率 62% → 69%），重標全部 231 萬則 | 隔夜效果 +4.4 → +3.5 bp；ΔAUC −0.0001 → −0.0001；**沒有變好** |
| 衰減校正 | 估計分類器雜訊讓效果剩約 76%（b = 0.76 ± 0.09） | 校正後隔夜約 +5.9 bp，上界 10~13 bp，仍不到成本三分之一 |
| 平台 | CMoney 同學會 | 隔天 +4.1 bp（t=4.9），PTT 同期 +8.0 bp（t=2.3）；只有成本的十分之一。**完整檢驗見 [研究八](09_cmoney.md)**：漲跌 AUC +0.003（PTT 0）、淨情緒可預測下個月，但扣成本後賺不到錢 |
| 股價來源 | Yahoo 還原價 → TEJ 還原價 | 數字只差小數點後一位 |
| 預測目標 | 隔天波動（最高/最低）、成交量 | ΔIC −0.0000／+0.0003（見下） |

程式：`classifier_noise_test.py`、`relabel_analysis.py`、`finetune_gold_cv.py`、`finetune_gold_infer.py`、`run_with_ft.py`、`cmoney_daily_test.py`、`tej_build_dataset.py`

### 5. 預測隔天波動與成交量（`vol_volume_test.py`，事先登記 V1、V2）

| 目標 | 基準 Rank IC | 加 PTT | 加融資融券 |
|---|---|---|---|
| 波動 | 0.725（樣本外 R² 0.49） | −0.0000（t=−0.3）❌ | +0.0001 |
| 成交量 | 0.562（R² 0.35） | +0.0003（t=1.9）⚠️ | +0.0012（t=7.5） |

- 迴歸上相關是顯著的：異常留言量每 +1 單位，隔天振幅 +2.0%（t=12）、成交量 +2.8%（t=17）；但解釋力只從 7.16% → 7.19%。
- 有 PTT 個股留言的股票日只占 7.5%，集中在少數熱門股（台積電一檔占三成）。

### 6. 依規模、依散戶持股分組

- 依規模分三組，最小那組 PTT 也沒有增量。
- 依散戶持股比例分三組，散戶多的組 PTT／CMoney 情緒並沒有比較準（見 [研究三](03_retail_trading.md)）。

## 判讀

PTT 與 CMoney 情緒描述得出當下的行情（CMoney 與當天漲跌相關 0.20、PTT 0.12），但對之後的漲跌、報酬、波動、成交量都沒有可用的預測力。換更準的分類器、換平台、換股價來源、換目標，結論都不變。

## 限制

- PTT 個股留言靠文章標題配對，集中在熱門股；閒聊串中提到個股的留言沒有分到個股。
- CMoney 熱門股是「收盤前最後 20 篇」的抽樣，且只有 2020 年以後；這個抽樣會讓「隔天開盤前情緒」偷看到隔天盤中熱度，已補抓開盤前貼文修正（見 [研究八](09_cmoney.md) 2.2）。
- 標準答案只有一位標註者（Claude）與 400 個股票日。
