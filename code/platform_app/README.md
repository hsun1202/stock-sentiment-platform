# 平台試作版（本機 Streamlit）

「結合市場情緒與財報資訊之股票虛擬交易平台」的試作介面，報告當天的備案，也當作給前端組員的具體範例（正式前端由組員做）。
版面與樣式參考組員 jameschen108/tw-stock-quant 的 `frontend/`（已取得使用者同意參考），資料讀取是自己寫的。

## 啟動

```bash
pip install streamlit plotly
cd D:/專題claude && python -m streamlit run platform_app/app.py --server.port 8502
```

瀏覽器開 `http://localhost:8502`。資料來自 `platform_feed`（每天 18:50 由工作排程器 `PTT_platform_feed_daily` 更新），重新整理頁面就會讀到新名單。

## 頁面

| 頁面 | 內容 |
|---|---|
| 今日名單 | 營收驚喜、盈餘驚喜、壞消息（避開）三張表；本月門檻、進場／出場日、進場以來報酬；點一列跳到個股 |
| 個股 | 收盤價與均線（標出驚喜／壞消息的進場日）、成交金額、近 24 個月營收與年增率、近 12 季淨利、PTT 討論量與淨情緒、目前的財報標籤 |
| 市場情緒 | PTT 盤中／盤後閒聊的每日淨情緒與留言數（含近 20 日平均、z 值）、今天討論最多的個股（淨情緒、熱度、財報標籤），點列跳個股 |
| 虛擬交易 | 帳戶（本金、現金、市值、未實現／已實現損益、淨值 vs 0050）、證交所即時報價（最佳五檔、漲跌停）、下單（台股規則）、持股（旁邊標出營收／盈餘壞消息）、委託紀錄與取消、重設帳戶 |
| 研究結果 | 兩個財報驚喜策略 2018–2026 的累積淨值（2026 為樣本外）vs 一般股票、0050；所有事先登記檢定的總表 |

## 注意

- 個股頁的月營收、季報歷史含 TEJ 匯出的數字（授權資料），只能在本機跑，不要部署到公開網址。
- 收盤價是證交所公開資料、未還原除權息，從 2025-09 開始。

## 虛擬交易規則（`trading.py`）

- 交易時段 09:00–13:30；盤中買單限價 ≥ 最佳賣價就以最佳賣價成交（賣單反之），沒成交的掛到收盤後用當天最高／最低判斷；
  盤後下的單排到下一個交易日，用開盤價撮合。當日有效。
- 整股 1 張＝1,000 股；零股 1–999 股（簡化：與整股同樣撮合）。
- 價格要符合升降單位、在漲跌停內（盤中直接用證交所公布的漲跌停）；整天鎖漲停買不到、鎖跌停賣不掉。
- 手續費 0.1425% × 折扣（無條件捨去，最低 20 元）；賣出證交稅股票 0.3%、ETF 0.1%。
- 簡化：成交即交割（實際 T+2）、不計除權息、不做當沖減稅、融資融券。
- 帳戶存在 `platform_app/data/account.json`（本機、單一使用者）。
- 檢查：`cd platform_app && python test_trading.py`（漲跌停和證交所即時資料比對 85 檔、84 檔相同，不同的是 0056 的漲停取整；
  升降單位、手續費、證交稅；下單、現金／庫存不足、盤中成交、收盤後撮合、盤後單隔天開盤成交、鎖漲停不成交）。
