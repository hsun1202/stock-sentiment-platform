# 平台試作版（本機 Streamlit）

「結合市場情緒與財報資訊之股票虛擬交易平台」的試作介面，報告當天的備案，也當作給前端組員的具體範例（正式前端由組員做）。
版面與樣式參考組員 jameschen108/tw-stock-quant 的 `frontend/`（已取得使用者同意參考），資料讀取是自己寫的。

## 啟動

```bash
pip install streamlit plotly
cd D:/專題claude && python -m streamlit run platform_app/app.py --server.port 8502
```

瀏覽器開 `http://localhost:8502`。資料來自 `platform_feed`（每天 18:50 由工作排程器 `PTT_platform_feed_daily` 更新），重新整理頁面就會讀到新名單。

## 頁面

| 頁面 | 內容 |
|---|---|
| 今日名單 | 營收驚喜、盈餘驚喜、壞消息（避開）三張表；本月門檻、進場／出場日、進場以來報酬；點一列跳到個股 |
| 個股 | 收盤價與均線（標出驚喜／壞消息的進場日）、成交金額、近 24 個月營收與年增率、近 12 季淨利、目前的財報標籤 |
| 研究結果 | 兩個財報驚喜策略 2018–2026 的累積淨值（2026 為樣本外）vs 一般股票、0050；所有事先登記檢定的總表 |

## 還沒有的

- 情緒（PTT、CMoney）每日資料：個股頁先留位置
- 虛擬下單（帳戶、委託、持股、台股交易規則）
- 上櫃股

## 注意

- 個股頁的月營收、季報歷史含 TEJ 匯出的數字（授權資料），只能在本機跑，不要部署到公開網址。
- 收盤價是證交所公開資料、未還原除權息，從 2025-09 開始。
