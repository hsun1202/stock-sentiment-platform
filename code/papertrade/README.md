# 紙上模擬交易（paper trading）

> 2026-10-22 建立。用證交所每天公布的真實行情，自動產生買賣訊號、模擬成交、記錄每個策略的虛擬部位與損益。**不動真錢、不下單。**
> 目的：把回測過的策略放到「之後才發生的行情」上跑，看它在真正的未來表現如何（回測再嚴謹，也比不上真的往前跑）。

## 每天做什麼（`run_daily.py`，工作排程器每個交易日 18:30 執行）

1. **更新資料**（`tw_data.py`、`update.py`）：從證交所抓還沒抓過的交易日
   - 每日收盤行情 MI_INDEX（全部上市股票的開高低收、成交股數、成交金額）
   - 除權息計算結果 TWT49U（除權息前收盤價、參考價）
   - 交易日曆 FMTQIK
   原始 JSON 存在 `raw/`，整理後的面板在 `data/prices.csv`。第一次執行會往回補約 90 個交易日，夠算 60 日波動。
2. **逐日處理每個策略**（`broker.py`），對每個還沒處理的交易日 d：
   1. 前一天收盤持有、d 當天除權息的股票 → 把（除權息前收盤價 − 參考價）× 股數記為現金（配股也用同樣方式近似）
   2. 用 d 的**開盤價**成交前一個訊號日留下的委託（先賣後買）；開盤就漲停的買不到、開盤就跌停的賣不掉（留到隔天再試）
   3. 用 d 的收盤價算淨值
   4. 如果 d 是換股日（第一次執行當天、每季第一個交易日），用 d 收盤為止的資料算新的目標權重，**隔天開盤**才成交（每季最後一個交易日要等之後才知道，所以用新一季的第一天）
3. **產生報告**（`report.py`）：`report/index.html`（淨值走勢圖、各策略與 0050 的比較、目前持股、最近成交）

## 策略（`strategies.py`；之後可以再加）

| 代號 | 規則 | 換股 |
|---|---|---|
| `highvol30` | 上市普通股中，近 60 日平均成交金額前 250 名；買近 60 日日報酬標準差最高的 30 檔，等權（組員 DAViS 延伸研究的規格） | 每季 |
| `lowvol30` | 同一母體，買波動最低的 30 檔（對照組） | 每季 |
| `ew250` | 同一母體 250 檔全部等權（「一般股票」基準） | 每季 |
| `etf0050` | 全部買 0050、一路持有（大盤基準，含息） | 不換 |

## 模擬假設

- 每個策略虛擬本金 1,000 萬元（100 萬分到 250 檔時，一股數千元的股票連一股都買不到）；可以買零股（股數取整數）。
- 成本：手續費 0.1425% × 6 折（買賣都收）；賣出證交稅股票 0.3%、ETF 0.1%；不收最低手續費。
- 成交價：訊號日的**隔天開盤價**（不是訊號當天收盤價，避免「用算訊號的價格成交」）。
- 只做多、不融資、不放空；目標權重以成交當下的淨值計算。
- 目前只含**上市**股票（上櫃股之後再加）。

## 檔案

| 路徑 | 內容 |
|---|---|
| `raw/` | 證交所原始 JSON（可重建） |
| `data/prices.csv` | 整理後的日資料（代號、日期、開高低收、成交股數、成交金額） |
| `data/exright.csv` | 除權息資料 |
| `state/{策略}.json` | 每個策略目前的現金、持股、待成交委託、最後處理日 |
| `state/{策略}_nav.csv`、`state/{策略}_trades.csv` | 每日淨值、每筆成交 |
| `report/index.html`、`report/nav.png` | 報告 |
| `run.log` | 每次執行的紀錄 |

## 怎麼用

```bash
cd D:/專題claude && python papertrade/run_daily.py            # 手動跑一次（會自動補齊漏掉的交易日）
python papertrade/run_daily.py --report-only                     # 只重產報告
```
