# 平台資料：營收驚喜、盈餘驚喜名單、PTT 每日情緒

給前端讀的每日資料。規則和 `ai_strategies/PREREG_ai_strategies.md` G、H 節完全相同（2018–2025 回測、2026 年 1～9 月樣本外都贏一般股票，但沒有贏 0050）。

## 每天更新

收盤後執行（證交所行情約 15:00 後；公開資訊觀測站的彙總表每天重新出表）：

```bash
cd D:/專題claude && python platform_feed/run_feed.py
```

步驟（紀錄寫在 `platform_feed/run.log`）：

1. 補證交所每日行情到 `data/prices.csv`（沿用 `papertrade/tw_data.py` 的抓取與快取）
2. 公開資訊觀測站快照：
   - 月營收：「上市公司營業收入彙總表」t21sc03（`mops_revenue.py`）
   - 季報：「上市公司綜合損益表彙總表」t163sb04（`mops_earnings.py`；年初累計數，之後換成單季）
   - 某公司某期**第一次出現在快照的日期＝公布日**；數值保留第一次看到的，之後的更正不覆蓋
3. 重算名單：`revenue_signals.py`、`earnings_signals.py`（共用 `feed_common.py`），輸出到 `out/`

**每天都要跑，週末也跑**（有公司在假日公布）。漏跑的日子，公布日會被記晚（名單晚一點出現，不會偷看）。

為什麼不用證交所 OpenAPI：月營收表整批更新（出表日期全部同一天），季報表只放申報期限已過的季度，都拿不到「哪一天公布」。累計轉單季、各產業欄位名稱不同的處理，參考組員 jameschen108/tw-stock-quant 的 `public_data.py`。

## 規則

| | 月營收驚喜 | 盈餘驚喜 |
|---|---|---|
| 驚喜分數 | （本月營收 − 去年同月）相對過去 24 個月同樣差額的標準化值 | （單季歸屬母公司淨利 − 去年同季）相對過去 8 季同樣差額的標準化值 |
| 持有 | 公布後第一個交易日開盤進場，20 個交易日 | 同左，60 個交易日 |
| 門檻 | 前 12 個月、上市、近 60 日成交金額中位數不在最低 20% 的公布事件，第 90／10 百分位 | 同左 |
| 標籤 | 最高 10%＝`營收驚喜`；最低 10%＝`營收壞消息（避開）` | `盈餘驚喜`；`盈餘壞消息（避開）` |

未來的出場日用平日估算（國定假日可能差幾天，`exit_is_estimate` 標 true）。

資料來源：TEJ 匯出（月營收到 2026-09、季報到 2026Q2，含發布日）＋之後用公開資訊觀測站快照。查核：2026-09 月營收 995 家、2026Q2 年初累計淨利 93%（其餘是沒有子公司、歸屬母公司欄空白的公司，已改用本期淨利）與 TEJ 相同；最近一期的分組和回測一致（月營收 100%；盈餘最高／最低組 97–99%）。

## 輸出檔：`out/revenue_signals.json`、`out/earnings_signals.json`

兩份格式相同（另有同名 `.csv` 可用 Excel 開）。

| 欄位 | 說明 |
|---|---|
| `asof` | 最新行情日 |
| `generated_at` | 產生時間 |
| `rule` | 規則一句話 |
| `thresholds` | 本月門檻：`month`、`p90`（驚喜）、`p10`（壞消息） |
| `surprise_active` | **目前持有期內的驚喜股票**（前端主名單） |
| `bad_news_active` | 目前持有期內的壞消息股票（避開標籤） |
| `all_recent` | 近期（營收 45 天、盈餘 100 天）公布的全部事件 |
| `disclaimer` | 免責文字，前端要顯示 |

每一筆共同欄位：

| 欄位 | 說明 |
|---|---|
| `code`、`name` | 代號、名稱 |
| `period` | 資料期別（營收 `2026-09`、季報 `2026Q2`） |
| `announce_date` | 公布日 |
| `entry_date`、`exit_date` | 進場日（公布後第一個交易日開盤）、出場日 |
| `exit_is_estimate` | 出場日是不是估的 |
| `surprise` | 驚喜分數（−10～10） |
| `decile` | 1～10 組 |
| `label` | 標籤或空字串 |

月營收另有 `revenue_k`（當月營收，千元）、`yoy`（年增率，0.25＝+25%）；盈餘另有 `net_income_k`（單季歸屬母公司淨利，千元）、`net_income_last_year_k`（去年同季）。

## 限制

- 只含上市股（回測只驗證過上市）。
- 月營收效果集中在中小型股；只買市值前 150 大扣成本後沒有超額。盈餘驚喜在大型股也有效（事後檢查，非事先寫定）。
- 公布日以「第一次出現在彙總表」為準；2026-11 起可用重大訊息公告時間驗證。
- 門檻用的歷史事件從 2025-10 起（股價從 2025-09 起），所以 2026 年上半年的分組和回測略有差異；2026-10 以後的月份已完整。

## PTT 每日情緒（`ptt_daily.py`、`ptt_sentiment.py`、`train_ptt_bert.py`）

- 爬蟲：www.ptt.cc Stock 板，每天往回掃最近 3 天發的文章、每篇重抓（閒聊串留言會一直增加），留言以（文章, 第幾則）去重存 `data/ptt/comments.csv`。
  第一次用 `python platform_feed/ptt_daily.py --days 60` 往回補（2026-10-26 補了 2,676 篇、37.5 萬則，約 20 分鐘）。
- 分類器：中文 BERT（ckiplab/bert-base-chinese）用全部 PTT 人工金標（6,300 則）微調，輸入「股票名｜標題｜推噓」＋留言
  （`train_ptt_bert.py` → `models/ptt_bert_context/`，約 400 MB，不上傳）。交叉驗證與金標一致率 69.2%、Kappa 0.44（研究用的 Breeze 62.3%、0.37）。
  分類結果快取在 `data/ptt/labels.csv`，每天只分新留言。
- 交易日：留言時間落在（前一交易日 13:30, 當天 13:30]；過去沒有行情的日子當休市（例：10/23 颱風）。
- 市場情緒：標題含「閒聊」（盤中／盤後閒聊）的留言；個股：標題提到股票（四碼代號或名稱；名稱互相包含時只留長的，常見詞只認代號）的文章底下的留言。
- 淨情緒＝(正 − 負) ÷ (正 + 負)；另附近 20 日平均、z 值、討論熱度（相對近 20 個有討論日的平均）。
- 排除：留言時間早於發文（文章內文引用的舊留言）或晚於現在（年份推錯），約 0.04%。
- 輸出：`out/sentiment_market.json`（`days`：每日 n、pos、neg、net、net_avg20、n_avg20、net_z）、
  `out/sentiment_stocks.json`（`top`：最新交易日討論最多的 50 檔；`series`：每檔每日 n、net）。
- **研究結論：PTT 情緒能描述市場氣氛，但不能預測之後的報酬 → 平台只當描述，不是買賣訊號。** CMoney「散戶極度悲觀」需要每天更新的 token，沒有接上。
