# 平台資料：月營收驚喜名單

給前端讀的每日資料。規則和 `ai_strategies/PREREG_ai_strategies.md` G、H 節完全相同（2018–2025 回測、2026 年 1～9 月樣本外都贏一般股票，但沒有贏 0050）。

## 每天更新

收盤後執行（證交所行情約 15:00 後、公開資訊觀測站營收彙總表每天重新出表）：

```bash
cd D:/專題claude && python platform_feed/run_feed.py
```

做三件事，紀錄寫在 `platform_feed/run.log`：

1. 補證交所每日行情到 `data/prices.csv`（沿用 `papertrade/tw_data.py` 的抓取與快取）
2. 抓公開資訊觀測站「上市公司營業收入彙總表」快照（`mops_revenue.py`）。某公司某月營收**第一次出現在快照的日期＝公布日**；營收值保留第一次看到的，之後的更正不覆蓋
3. 重算名單（`revenue_signals.py`），輸出 `out/revenue_signals.json`、`out/revenue_signals.csv`

**每天都要跑**：漏跑的日子，那幾天公布的公司公布日會被記晚（名單會晚一點出現，不會偷看）。

## 規則

- 營收驚喜 SUR＝（本月營收 − 去年同月）相對過去 24 個月同樣差額的標準化值
- 每月門檻：前 12 個月、上市、近 60 日成交金額中位數不在最低 20% 的公布事件，取第 90／10 百分位
- 最高 10%＝「營收驚喜」，最低 10%＝「營收壞消息（避開）」
- 公布日後第一個交易日開盤進場，持有 20 個交易日；未來的出場日用平日估算（國定假日可能差幾天，`exit_is_estimate` 會標 true）

營收歷史：TEJ 匯出到 2026-09（含發布日），之後的月份用公開資訊觀測站快照。2026-09 兩邊 995 家數字 100% 相同。

## `out/revenue_signals.json` 欄位

| 欄位 | 說明 |
|---|---|
| `asof` | 最新行情日 |
| `generated_at` | 產生時間 |
| `rule` | 規則一句話 |
| `thresholds` | 本月門檻：`month`、`p90`（驚喜）、`p10`（壞消息） |
| `surprise_active` | **目前持有期內的「營收驚喜」股票**（前端主名單） |
| `bad_news_active` | 目前持有期內的「營收壞消息」股票（避開標籤） |
| `all_recent` | 近 45 天公布的全部事件（含中間組） |
| `disclaimer` | 免責文字，前端要顯示 |

每一筆：

| 欄位 | 說明 |
|---|---|
| `code`、`name` | 代號、名稱 |
| `revenue_month` | 營收月份（例 `2026-09`） |
| `announce_date` | 公布日 |
| `entry_date`、`exit_date` | 進場日（公布後第一個交易日開盤）、出場日 |
| `exit_is_estimate` | 出場日是不是估的 |
| `revenue_k` | 當月營收（千元） |
| `yoy` | 年增率（0.25＝+25%） |
| `surprise` | 驚喜分數 SUR（−10～10） |
| `decile` | 1～10 組（依本月門檻） |
| `label` | `營收驚喜`、`營收壞消息（避開）` 或空字串 |

## 限制

- 只含上市股（回測只驗證過上市）。
- 效果集中在中小型股；只買市值前 150 大扣成本後沒有超額。
- 盈餘驚喜（季報）還沒接上，下一步做。
